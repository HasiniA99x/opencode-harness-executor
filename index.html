Narrative

Same order as a real PR-review OpenCode execution.

  1. 1GitHub fires a webhook when label ai-dlc/pr/pr-review-opencode is applied (or PR opens/syncs with it).
  2. 2Agent Knowledge rules.json matches github-pull-request-review-opencode.
  3. 3Control plane starts Docker image 99xio/xianix-executor-opencode:latest with vault secrets.
  4. 4Inside the container, Claude CLI installs the marketplace plugin and stages installPath.
  5. 5plugin_runtime.py converts Claude .md commands/skills into WORK_DIR/.opencode/.
  6. 6execute_opencode.py runs opencode run with the model and execute-prompt.
  7. 7Stdout returns a JSON envelope (status, result, tokens) to the agent.
