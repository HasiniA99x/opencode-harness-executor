Step 5 · execute_opencode.py

opencode run → JSON envelope

After plugins are converted, the harness invokes OpenCode with the model from rules and returns a structured result on stdout.

Model + keys

Model ids look like provider/model. Matching API keys must be injected via with-envs.

"model": "openai/gpt-5.3-codex"
# requires OPENAI-API-KEY in the container env

# alternate examples
"model": "anthropic/claude-sonnet-4-5"   # needs ANTHROPIC-API-KEY

Typical prompt

You are reviewing pull request #{{pr-number}} in the repository {{repository-name}}.
Run /pr-review {{pr-number}} to perform the automated review.
Host context (platform CLI notes, plugin recipe) is prepended by host_context.py before OpenCode sees the user prompt.

Result envelope (illustrative)

Stdout is one JSON object the agent parses — progress logs go to stderr.

{
  "tenant_id": "default",
  "execution_id": "30e1d2dc",
  "harness": "opencode",
  "status": "completed",
  "models": ["openai/gpt-5.3-codex"],
  "result": "… agent reply text …",
  "error": null
}
On failure, status is error and error carries the message (e.g. missing staged plugins).
