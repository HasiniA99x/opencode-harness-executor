with-envs (mandatory vault secrets)

secrets.* resolves from the tenant Secret Vault — not the host .env.

"with-envs": [
  { "name": "GITHUB-TOKEN", "value": "secrets.GITHUB-TOKEN", "mandatory": true },
  { "name": "OPENAI-API-KEY", "value": "secrets.OPENAI-API-KEY", "mandatory": true }
]
Mandatory empty = container aborted. If vault keys are missing or undecryptable, the agent never starts Docker.

use-plugins + prompt

"use-plugins": [{
  "plugin-name": "pr-reviewer@xianix-plugins-official",
  "marketplace": "xianix-team/plugins-official"
}],
"execute-prompt": "… Run /pr-review {{pr-number}} …"
Slash command must match the plugin (/pr-review for Xianix pr-reviewer). Bare Anthropic code-review needs /code-review and a qualified plugin-name@marketplace id.
