Claude install → OpenCode convert

Plugins from any marketplace

The harness installs Claude Code plugins at runtime, stages installPath, converts markdown into .opencode/, then runs OpenCode. Official Xianix and Anthropic plugins both work.

A · Xianix official (pr-reviewer)

Default OpenCode PR-review path in agent Knowledge.

"use-plugins": [
  {
    "plugin-name": "pr-reviewer@xianix-plugins-official",
    "marketplace": "xianix-team/plugins-official"
  }
],
"execute-prompt": "You are reviewing pull request #{{pr-number}} in the repository {{repository-name}}. Run /pr-review {{pr-number}} to perform the automated review."

B · Anthropic marketplace (code-review)

Same OpenCode harness — different plugin source. Use the qualified marketplace id.

"use-plugins": [
  {
    "plugin-name": "code-review@claude-code-plugins",
    "marketplace": "anthropics/claude-code"
  }
],
"execute-prompt": "You are reviewing pull request #{{pr-number}} in the repository {{repository-name}}. Run /code-review {{pr-number}} to perform the automated review."
Must include @claude-code-plugins. Bare code-review installs but staging cannot find installPath, so conversion fails.

Shared pipeline

  1. 1claude plugin marketplace add (fresh clone)
  2. 2claude plugin install plugin@marketplace --scope project
  3. 3Stage installPath → XIANIX_PLUGINS_DIR/<name>/
  4. 4plugin_runtime.py converts .md → WORK_DIR/.opencode/
  5. 5opencode run (not Claude Code for the prompt)
