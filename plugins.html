Step 4 · Claude install → OpenCode convert

How plugins become OpenCode skills

The harness still uses Claude Code CLI for marketplace install, then converts markdown into an OpenCode overlay before the prompt runs.

Pipeline

From run_prompt.sh + plugin_runtime.py.

  1. 1claude plugin marketplace remove (stale) then marketplace add (fresh clone).
  2. 2claude plugin install plugin@marketplace --scope project.
  3. 3Read installPath from claude plugin list --json and stage under XIANIX_PLUGINS_DIR/<name>/.
  4. 4Convert Claude commands/, agents/, skills/ .md → WORK_DIR/.opencode/.
  5. 5opencode run — not Claude Code — executes the prompt.
claude plugin marketplace add / plugin install
        ↓ stage installPath
XIANIX_PLUGINS_DIR/<id>/{commands,agents,skills}
        ↓ convert .md only

        ↓
opencode run

Plugin id must include the marketplace

Common failure: bare code-review installs as code-review@claude-code-plugins, but staging looks up the bare id → no installPath → empty plugin dir → convert aborts. 
# good — Xianix official
"plugin-name": "pr-reviewer@xianix-plugins-official",
"marketplace": "xianix-team/plugins-official"

# good — Anthropic bundled marketplace
"plugin-name": "code-review@claude-code-plugins",
"marketplace": "anthropics/claude-code"

Slash command must match

pr-reviewer
/pr-review
code-review
/code-review

The execute-prompt must call the command the converted plugin actually exposes.
