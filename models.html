Models you can run with OpenCode

OpenCode uses provider/model ids (AI SDK + Models.dev — 75+ providers). Set model on the execution block and inject the matching API key via with-envs. See opencode.ai/docs/models.

Example rules.json model values

# format: provider_id/model_id
"model": "openai/gpt-5.3-codex"          # needs OPENAI-API-KEY
"model": "openai/gpt-5.2"
"model": "openai/gpt-5.1-codex"
"model": "anthropic/claude-sonnet-4-5"   # needs ANTHROPIC-API-KEY
"model": "anthropic/claude-opus-4-5"
"model": "google/gemini-3-pro"          # needs Google credentials
"model": "opencode/gpt-5.1-codex"       # OpenCode Zen
"model": "lmstudio/google/gemma-3n-e4b" # local via LM Studio
Xianix wiring: the agent passes the rules model into the container as XIANIX-MODEL. Pair it with the right vault secret in with-envs.

Variants (optional)

OpenCode supports reasoning effort / thinking budgets per provider (high, low, max, …). Configure in OpenCode config when you need them; the harness mainly sets the base provider/model.
