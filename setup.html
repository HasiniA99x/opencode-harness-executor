How to try it on your stack

Checklist for a real OpenCode PR review. This demo site stays static.

1. Pull the image

docker pull 99xio/xianix-executor-opencode:latest

2. Tenant secrets

Studio → Settings → Secrets · tenant scope · exact key names.

GITHUB-TOKEN
repo PAT
OPENAI-API-KEY
for openai/* models

3. Knowledge knobs

  1. 1Set executor-image to 99xio/xianix-executor-opencode:latest.
  2. 2Pick a model (see Models) and matching secret.
  3. 3Choose plugin: Xianix /pr-review or Anthropic /code-review (see Plugins).

4. Trigger

Apply label ai-dlc/pr/pr-review-opencode on an open PR (or use your Knowledge match rules).
