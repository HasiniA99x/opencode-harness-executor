How to try it on your stack

Checklist for running a real OpenCode PR review against your Xians agent. This demo site itself stays static.

1. Pull the image

docker pull 99xio/xianix-executor-opencode:latest

2. Tenant secrets (Studio → Settings → Secrets)

Tenant scope. Keys must match rules exactly (hyphens).

GITHUB-TOKEN
PAT with repo access
OPENAI-API-KEY
for openai/* models
If secrets were created under an old encryption key, delete and recreate them under the current Server key.

3. Knowledge rules

  1. 1Ensure block github-pull-request-review-opencode exists with label ai-dlc/pr/pr-review-opencode.
  2. 2Set executor-image to 99xio/xianix-executor-opencode:latest.
  3. 3Use pr-reviewer@xianix-plugins-official + prompt /pr-review.

4. Trigger

On an open PR, apply label ai-dlc/pr/pr-review-opencode. Watch agent logs for prepare → plugin install → staged → opencode run.

This page does not call GitHub or your agent — it only documents the path.
